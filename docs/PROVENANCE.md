# Provenance

The scientific files in this repository are copied from frozen commits of `byDenoso/Pantheon`.

- G0-G19 publication baseline: `1e944e34f30d3d4948f60a6f045e5557d733c8b6`
- H0-H6 hardening layer: `3aaec79fd6e6b43931a29d03afa4676c2163af6d`

The hardening commit is one commit ahead of the primary baseline and adds the hardening layer without rewriting the frozen G0-G19 source.

`UPSTREAM_SOURCES.json` records the exact source commit and Git blob SHA-1 for every copied scientific file. Matching a file's blob SHA against that manifest is the file-level identity test.
